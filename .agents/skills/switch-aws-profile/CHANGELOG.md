# Changelog

## [0.1.0]

### Added
- Control every feature of the switch-profile CLI 2.6.0+ in plain language: list and switch profiles, SSO logins, import portals, create, rename and remove profiles, portals and settings
- Guide setup decisions: profile kind, SSO region vs default region, names, login mode
- Hand off to the user's terminal what must not pass through an agent: access keys, and console sign-in without a browser
